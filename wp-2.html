Overview

  1. Create Grid for defined boundary area (as per most suitable format)
  2. Retrieve OSM layer data

These layers are required: - Buildings - Landuse - Railways - Roads - Traffic - Transport - Water - Waterways

Each layer should be split by its fclass or type to count the specific unique feature length/area in each grid cell

  1. Filter OSM data to select specific layers and split by fclass
  2. Clean overlapping features
  3. Calculate total size of each feature (either length or area)
  4. Intersect with grid
  5. Calculate the area of each feature in each grid cell (either length or area)
  6. Calculate the percentage of element in each grid cell
  7. Package result in CSV with WKT geometry (EPSG 4326)

Notes draft script 2022.07.05

  • Discuss the fclass partitions. An fclass like ‘building’ for an area like London can have as much as 317 classes. Does it worth to partition the data in so many classes. Perhaps it is better to choose top N and recode ‘others’
  • An area like London is tessellated in more than 12 million hexagons
  • See summary by ‘layer’. What geometries to select? Is removing NA a valid approach?

# ref function creation: https://mran.microsoft.com/snapshot/2017-09-15/web/packages/dplyr/vignettes/programming.html
# this function takes an sf dataframe, a key name and an h numerical to obtain a character of h highest values by key

values <- function(df, key, h) {
  
  qkey <- enquo(key)
  
  df %>%
    st_drop_geometry() %>%
    filter(!is.na(!!qkey)) %>%
    group_by(!!qkey) %>%
    count() %>%
    arrange(desc(n)) %>%
    ungroup() %>%
    slice_head(n = h) %>%
    pull(!!qkey) 
}

values_k <- values(mpg, landuse, 5)
Code 
# recode to 'other' values that are not in highest occurrences
# this function takes an sf dataframe, a key name and to recode to 'other' those values that are not in the h highest values. 
# resulting sf has only the selected key name

recother <- function(df, key) {
  
  qkey <- enquo(key)
  
  df %>%
    filter(!is.na(!!qkey)) %>%
    mutate(!!qkey := case_when(!!qkey %in% values_k ~ !!qkey,
                               TRUE ~ "other")) %>%
    select(!!qkey)
}

recother(mpg, landuse) -> mpg_r

# create multipolygons statistics by hexagon = landuse
hp_int %>%
  # calculate area
  mutate(area = as.numeric(st_area(.))) %>%
  st_drop_geometry() %>%
  # classes areas as variables
  pivot_wider(names_from = "landuse", values_from = "area", values_fn = sum, values_fill = 0) -> hp_int_j

hp_int_j %>%
  # add prefix to columns 2 onwards
  rename_with( ~ paste0("l_", .x), .cols = 2:ncol(.)) %>%
  mutate_all( ~ replace(., is.na(.), 0)) %>%
  # add total
  mutate(total = rowSums(.[2:ncol(.)])) %>%
  # add percentage by column
  mutate_at(vars(starts_with("l")) , funs(pc = ./total * 100)) -> hp_int_j1
